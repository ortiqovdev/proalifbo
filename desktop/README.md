# Pro Alifbo — Windows x64

Portable paketni alohida papkaga oching va ProAlifbo.exe faylini ishga tushiring. Oynani yopish uni soat yoniga yig‘adi. Yashil belgiga chap bosish oynani ochadi. O‘ng bosish orqali Avtoyozuvni almashtirish yoki dasturdan chiqish mumkin.

Avtoyozuv yoqilganda odatiy matn maydonida klaviaturadan terilgan so‘z probeldan keyin yangi alifboga o‘tadi. Windows yuqoriroq huquqda ishlayotgan oynaga va himoyalangan ish stoliga tugma yuborishni cheklaydi. Yozilgan so‘z vaqtincha xotirada turadi. Dastur diskka faqat rejimni saqlaydi.

Yig‘ish: 64-bit Windows’da npm ci, node node_modules/electron/install.js va npm run build buyruqlarini bajaring. Natija dist/ProAlifbo papkasida. Konvertor mobil va web ilova bilan umumiy shared modullaridan foydalanadi.
