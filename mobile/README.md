# Pro Alifbo mobil ilovasi

Android emulyatori yoki telefonida: Android SDK va JDK 17 o‘rnatilgan muhitda `npm ci`, keyin `npm run android`.
iOS uchun: Xcode va CocoaPods o‘rnatilgan Mac kompyuterida `npm ci`, keyin `npm run ios`. Kamerani iPhone qurilmasida sinang. Simulyatorda galereyadan rasm tanlash mumkin.

OCR native moduldan foydalanadi, shuning uchun ilovani native build sifatida ishga tushiring. Android uchun lotin yozuviga mo‘ljallangan ML Kit modeli ilovaga qo‘shilgan. iOS Apple Vision’dan foydalanadi. OCR aniqligi rasm sifati va yozuvga bog‘liq. O‘qilgan matnni konvertatsiyadan oldin tahrirlash mumkin.

### Pro Alifbo tizim klaviaturasi

Android’da ilovani o‘rnating, Sozlamalar → Tizim → Klaviatura → Ekran klaviaturasi bo‘limida Pro Alifbo’ni yoqing. Matn maydonida klaviaturalar menyusidan Pro Alifbo’ni tanlang.

iOS’da klaviatura kengaytmasi bilan native ilovani o‘rnating. Sozlamalar → Asosiy → Klaviatura → Klaviaturalar orqali Pro Alifbo’ni qo‘shing. Matn maydonida globus tugmasi bilan unga o‘ting. Expo Go tizim klaviaturasini o‘rnatmaydi.

Pro Alifbo ilovasidagi **Avtoyozuv** yoqilganda probel oxirgi so‘zni yangi alifboga o‘giradi. Klaviatura bu tanlovni eslab qoladi.
